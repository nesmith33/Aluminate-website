# Aluminate brand reference — v1.10

Primary accent blue: **#83C9FF** — sourced from the v1.9 homepage `Engineered.` text, where it was defined as the CSS `--blue` value.

Typography: **Inter**, with Arial/Helvetica fallback. This follows the existing site CSS; actual appearance depends on Inter being installed unless web fonts are added.

Page eyebrow labels: 13px, 800 weight, 2.5px tracking, uppercase.
Hero headlines: Inter 800, responsive 46–82px on interior pages, 1.02 line height, -0.045em tracking. The homepage retains its approved hero-specific sizing.
Hero descriptors: Inter, responsive 16–20px, line-height 1.48.
Section headings: Inter 800, responsive 30–49px, line-height 1.1, -0.035em tracking.
Navigation: 14px. Header tagline: 12px.
CTA blue hover: #A9DFFF with dark text retained.

This document records the v1.10 website implementation, not a finalized print brand standard.
